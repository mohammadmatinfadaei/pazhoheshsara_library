# 📚 Pazhoheshsara Library
### سامانه مدیریت هوشمند کتابخانه پژوهشسرا

سامانه مدیریت کتابخانه پژوهشسرا، یک نرم‌افزار کاربردی برای مدیریت و سامان‌دهی فرایندهای کتابخانه‌ای است که با هدف تسهیل امور کتابداری، افزایش دقت در ثبت اطلاعات و بهبود مدیریت منابع و اعضا طراحی و توسعه داده شده است.

## ✨ امکانات اصلی

- 📖 **مدیریت کتاب‌ها:** ثبت، مشاهده، ویرایش و حذف اطلاعات کتاب‌ها
- 👨‍🎓 **مدیریت دانش‌آموزان:** ثبت و نگهداری اطلاعات اعضای کتابخانه
- 🔄 **مدیریت امانت:** ثبت امانت کتاب‌ها و مدیریت فرایند بازگشت آن‌ها
- ⏰ **پیگیری دیرکرد:** بررسی تأخیر در بازگرداندن کتاب‌ها و مدیریت وضعیت اعضا
- 🪪 **مدیریت اعتبار عضویت:** بررسی تاریخ انقضای کارت عضویت و وضعیت دانش‌آموزان
- 📊 **داشبورد مدیریتی:** نمایش آمار و اطلاعات کاربردی کتابخانه
- 📥 **ورود اطلاعات از Excel:** تسهیل انتقال اطلاعات کتاب‌ها و دانش‌آموزان
- 🔐 **احراز هویت مدیران:** مدیریت دسترسی و نگهداری امن رمزهای عبور به‌صورت هش‌شده
- 📝 **ثبت فعالیت‌ها:** ثبت رویدادها و فعالیت‌های مدیریتی برای نظارت بهتر

## 🛠️ فناوری‌های استفاده‌شده

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML, CSS و JavaScript
- OpenPyXL برای پردازش فایل‌های Excel

## 🚀 راه‌اندازی پروژه

۱. مخزن را دریافت کنید:

```bash
git clone https://github.com/mohammadmatinfadaei/pazhoheshsara_library.git
```

۲. وارد پوشه پروژه شوید:

```bash
cd pazhoheshsara_library
```

۳. محیط مجازی پایتون بسازید و فعال کنید:

```bash
python -m venv venv
```

در ویندوز:

```cmd
venv\Scripts\activate
```

۴. وابستگی‌های موردنیاز را نصب کنید:

```bash
pip install Flask Flask-SQLAlchemy Flask-Cors openpyxl
```

۵. فایل اصلی برنامه را اجرا کنید:

```bash
python app.py
```

*نام فایل اصلی و وابستگی‌ها را در صورت تفاوت با ساختار واقعی پروژه تنظیم کنید.*
